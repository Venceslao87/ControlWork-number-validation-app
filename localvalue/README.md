# Number Validation & Evaluation App

A simple console application written in C# (.NET) to practice core programming concepts: input validation loops, modular methods, and modern pattern matching.

## Features
* Input Validation: A dedicated Validation() method with an infinite loop (while (true)) that ensures the user enters a valid number within the 0–100 range.
* Modular Architecture: Clean separation of concerns with distinct methods for input checking (Validation) and logical evaluation (Answer).
* Pattern Matching: Utilizes modern C# switch expressions with arrow syntax (=>) to evaluate whether the number is greater than, less than, or equal to 50.

## Tech Stack
* Language: C# (.NET Core)
* Environment: Visual Studio
